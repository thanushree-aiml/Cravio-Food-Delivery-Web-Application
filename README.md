# 🍔 CRAVIO - Food Delivery Web Application

CRAVIO is a full-stack food delivery web application inspired by Swiggy/Zomato, built using Java Servlets, JSP, JDBC, and MySQL. 

## 🚀 Features
* **User Authentication:** Secure Login, Signup, and Forgot Password using BCrypt encryption.
* **Dynamic Cart:** Add, update, and remove items with a Swiggy-style UI.
* **Order Placement:** Checkout flow, order generation, and order history tracking.
* **Admin Panel:** Role-based access for restaurant management.
* **Responsive UI:** Modern, mobile-friendly design with Dark/Light mode.

## 🛠️ Tech Stack
* **Backend:** Java, Jakarta Servlets, JSP, JDBC
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Database:** MySQL
* **Server:** Apache Tomcat 10.1
